# Learn Go Repository

Welcome to the **Learn Go** repository! This project is organized to help you learn and master the Go programming language, following the [roadmap.sh Go roadmap](https://roadmap.sh/golang). The repository is structured into folders, each focusing on a specific topic or feature of Go. Happy coding! 🚀

---

## Folder Structure

### 1. Basics
Learn the fundamental building blocks of Go:
- **`01_basics/variables_and_types/`**: Introduction to variables, constants, and data types.
- **`01_basics/functions/`**: Understanding functions, parameters, and return values.
- **`01_basics/control_structures/`**: If-else, switch statements, and loops.
- **`01_basics/arrays_and_slices/`**: Work with arrays and slices in Go.
- **`01_basics/maps/`**: Learn about Go's map data structure.
- **`01_basics/structs_and_methods/`**: Define and use structs, along with methods.

### 2. Intermediate
Deepen your knowledge with more advanced topics:
- **`02_intermediate/pointers/`**: Understand pointers and their usage.
- **`02_intermediate/interfaces/`**: Learn about Go's interfaces and polymorphism.
- **`02_intermediate/concurrency/`**: Explore goroutines, channels, and sync packages.
- **`02_intermediate/error_handling/`**: Effective error handling in Go.

### 3. Advanced
Master Go's advanced features:
- **`03_advanced/file_handling/`**: Read and write files in Go.
- **`03_advanced/testing/`**: Create and run unit tests.
- **`03_advanced/generics/`**: Learn about Go's generics.
- **`03_advanced/reflection/`**: Explore Go's reflection capabilities.

### 4. Building CLI Tools
Build command-line applications with Go:
- **`04_building_cli_tools/cobra/`**: Create CLI tools using the Cobra library.
- **`04_building_cli_tools/flag/`**: Use Go's built-in `flag` package.
- **`04_building_cli_tools/custom_tools/`**: Experiment with custom CLI applications.

### 5. Web Development
Learn to build web applications:
- **`05_web_development/http_server/`**: Create basic HTTP servers.
- **`05_web_development/rest_api/`**: Build RESTful APIs.
- **`05_web_development/gorilla_mux/`**: Use Gorilla Mux for routing.

### 6. Database
Work with databases in Go:
- **`06_database/sql/`**: Use the `database/sql` package for SQL databases.
- **`06_database/orm/`**: Learn ORMs like GORM.
- **`06_database/nosql/`**: Work with NoSQL databases like MongoDB.

### 7. Deployment
Learn how to deploy your Go applications:
- **`07_deployment/building_binaries/`**: Build and distribute binaries.
- **`07_deployment/docker/`**: Containerize your Go apps using Docker.
- **`07_deployment/ci_cd/`**: Set up CI/CD pipelines.
- **`07_deployment/versioning/`**: Learn about versioning and releases.

## How to Use This Repository

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/learn-go.git
   cd learn-go
   ```

2. **Explore the topics**:
   Each folder contains examples and exercises for the topic. Navigate to the desired topic and run the examples.

3. **Run examples**:
   Use the Go CLI to run examples. For instance:
   ```bash
   cd 01_basics/variables_and_types
   go run main.go
   ```

4. **Practice**:
   Try modifying the examples or adding your own to deepen your understanding.
